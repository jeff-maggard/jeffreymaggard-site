The system

The Moderation Hub is a low-code system that automates writing moderation (grading calibration) for four English foundation courses.

How it works

  • Lecturers score three anonymized writing samples in one Microsoft Form.
  • When the session closes, every lecturer receives one email. It shows their mark for each rubric criterion directly above the key mark (the course lead’s or the cohort median), with differences over 0.5 highlighted.
  • Lecturers outside the range automatically mark an extra sample and get instant feedback.
  • If a lecturer remains outside the range, the course lead is alerted and receives a visual summary.
  • A Control Room lets each course lead run the whole system.
  • A one-button semester reset archives the results, with a name-free summary for accreditation.

Orientation

A 5-minute Rise 360 orientation, published as SCORM 2004 and deployed in Blackboard Ultra.

Status

Built and tested with invented data. A pilot is planned for Spring 2027.

Built with AI assistance, with documented human review.
