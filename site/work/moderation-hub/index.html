Automated Writing Moderation System

The purpose

At every midterm and final exam in Qatar University’s FPDE (Foundation Program Department of English), lecturers mark writing samples in a moderation session, so that grading is consistent and fair.

Done by hand, it takes about 20 hours per course lead each semester: sending emails, collecting scores, analyzing them, sending feedback to every lecturer and keeping records. I built this system to do all of that automatically.

Every session is archived, so the department builds a record of marking accuracy over time. That evidence supports data-driven review: we can see where calibration drifts, target training where it is needed, and reflect on and improve our assessment practice.

What the course lead does

  1. Set up the session in SharePoint lists: the exam, the opening and closing dates, and the key (their own marks or the cohort median).
  2. Upload three anonymized samples of student writing to SharePoint.

That is the whole setup. Everything else runs on its own.

What happens automatically

  1. Power Automate emails every lecturer when the session opens.
  2. Lecturers score the three samples in one Microsoft Form.
  3. When the session closes, Power Automate compares every mark with the key.
  4. Each lecturer gets one email with their marks directly above the key for each rubric criterion. Differences over 0.5 are highlighted.
  5. A lecturer outside the range is sent one more sample with instant feedback. If they are still outside the range after two extra samples, the course lead and their delegate are alerted.
  6. The course lead receives a session summary.
  7. Resubmissions, late submissions and incomplete or mistaken submissions are handled automatically.
  8. At the end of the semester, one button archives the results, with a name-free summary for CEA accreditation.

Why it matters

  • Saves each course lead about 20 hours a semester.
  • Frees the faculty member who was assigned to run moderation for other work that builds the program.
  • Shows course leads which lecturers need support, so they can help them early.
  • Provides documented evidence of assessment quality for CEA accreditation.

From version 1 to version 2

Version 1 ran the calculations in an Excel workbook. An independent design review found it would be fragile at scale (form-to-workbook syncing, file locking and row limits), and the department’s e-learning committee recommended the university’s enterprise Power Automate.

Version 2 moves every scoring rule into Power Automate flows and SharePoint lists. I checked every rule against a reference model and a 10-case test plan with expected results.

Next steps

The department has approved the design, and it is being set up with the e-learning committee. A pilot is planned for Spring 2027 with the Embedded Foundation courses. If it works well, it can expand to the Foundation Program and Post-Foundation courses.
